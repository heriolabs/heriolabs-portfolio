Heriolabs Portfolio Website

Files:
- index.html: the website homepage. Upload this file to the root of your GitHub repository.
- README.txt: these instructions; optional for publishing.

Publishing with GitHub Pages:
1. Upload index.html to the root of your public repository.
2. Open repository Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Choose branch main and folder /(root), then Save.

Contact form:
The form prepares an email addressed to heriolabs@gmail.com using the visitor’s email app. It does not send automatically or store submissions on a server.
